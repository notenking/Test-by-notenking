# StudyOS 0.0.21 — Download

This branch contains the standalone StudyOS website. It is separate from the project’s main branch.

## 下载与打开

1. [下载 ZIP 压缩包](./StudyOS_0.0.21_HTML_only.zip?raw=true)。
2. 解压后，双击 `StudyOS_0.0.21.html`，使用 Chrome 或 Edge 打开。
3. 不需要安装扩展程序即可使用计划与计时功能。网站屏蔽仍需要原有扩展。

也可以打开 [HTML 文件页面](./StudyOS_0.0.21.html)，使用 GitHub 的 Download raw file 按钮保存。

更新前请保留旧版本，并先导出原有数据备份。浏览器可能将不同地址或本地文件的数据分别保存；若新文件没有显示旧记录，请使用产品内的备份导入功能恢复。

## Open the app

Download the ZIP, extract it, and open `StudyOS_0.0.21.html` in Chrome or Edge. The HTML includes its scripts, styles, and icons.

This package contains no sample tasks or user records. Existing records remain in the browser storage used by the previous version. Export a backup before switching files and import it if your records are not visible.
